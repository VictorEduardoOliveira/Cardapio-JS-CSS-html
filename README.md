# 🍔 Cardápio Interativo — MC Donalds (HTML, CSS e JS)

Página de cardápio interativo inspirada no McDonald's, com carrinho de compras funcional construído em **HTML, CSS e JavaScript puro**.

🔗 **[Ver demo ao vivo](https://victoreduardooliveira.github.io/Cardapio-JS-CSS-html/)**

## 📋 Sobre o projeto

O projeto simula a experiência de pedir um lanche por um cardápio digital, incluindo:

- 🍔 Vitrine de produtos (Big Mac, Duplo Quarterão, Tasty Turbo 3 Carnes) com foto, descrição e preço;
- 🛒 **Carrinho de compras** com contador de itens, subtotal e total calculados dinamicamente via JavaScript;
- 🚚 Escolha entre **Delivery** ou **Retirada na loja**;
- 📍 Formulário de endereço de entrega, com seleção de cidade, bairro e rua;
- 💳 Seleção de forma de pagamento (Dinheiro, Cartão de Débito ou Cartão de Crédito);
- ✅ Finalização do pedido.

## 🛠️ Tecnologias utilizadas

- **HTML5** — estrutura da página
- **CSS3** — estilização visual do cardápio
- **JavaScript** — lógica do carrinho de compras (adicionar itens, calcular subtotal/total, controlar o fluxo do pedido)

## ⚙️ Como executar

Não é necessário nenhuma instalação — é uma página estática.

1. Clone o repositório:
   ```bash
   git clone https://github.com/VictorEduardoOliveira/Cardapio-JS-CSS-html.git
   ```
2. Abra o arquivo `index.html` diretamente no navegador.

   Ou, se preferir usar um servidor local (recomendado para evitar bloqueios de recursos):
   ```bash
   npx serve .
   ```
